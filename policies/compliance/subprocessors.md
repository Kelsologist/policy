# Subprocessors and Third-Party Disclosures

**Effective date:** 2026-08-29  
**Last updated:** 2026-08-29  
**Version:** 1.0.0

This document lists subprocessors and third-party services that may process data on our behalf.

## Subprocessor Categories
- Cloud hosting providers
- Email/notification providers
- Analytics/monitoring tools
- Customer support platforms

## Disclosure Fields
For each subprocessor, maintain:
- Provider name
- Purpose of processing
- Data categories involved
- Processing region(s)
- Link to provider security/privacy documentation

## Change Management
When subprocessors change:
1. Update this file
2. Add a changelog entry
3. Notify users/customers when required by contract or law
